# Next Frame

A small, deterministic anime recommendation app powered by Jikan. Pick three distinct anime and receive one SFW, discovery-first recommendation based on eligible related titles and metadata similarity.

## Run locally

Install dependencies, then start the Vite development server:

```bash
npm install
npm run dev
```

Run checks with:

```bash
npm test
npm run build
```

The app stores selections only in memory. It does not use accounts, a database, a backend, or an AI service.
